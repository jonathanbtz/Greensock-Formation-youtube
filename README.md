# GSAP — Formation YouTube

Code source de la formation **GSAP** disponible sur la chaîne YouTube **La Minute de Code**.

Cette formation permet d'apprendre à créer des animations web fluides et avancées avec GSAP.

## 🎬 Au programme

- Introduction à GSAP
- Installation et configuration
- gsap.to()
- gsap.from()
- gsap.fromTo()
- Durée et delay
- Easing
- Transformations
- Animations en chaîne
- Timelines
- Stagger
- Scroll animations
- ScrollTrigger
- Interactions
- Animations d'interfaces
- Projets pratiques

## 💻 Code source

Ce repository contient le code et les exemples utilisés dans les différents épisodes de la formation GSAP.
